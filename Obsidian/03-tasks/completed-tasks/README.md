# Completed Tasks Archive

Historical feature changelogs organized by category.

## Folder Structure

- **systems/** - Core game systems (hideout, radar, expansion, logging)
- **combat/** - Combat-related features (damage, melee, enemy rendering)
- **ui/** - UI and player improvements (character system, sprites, camera)
- **architecture/** - Architectural refactors (signals, arena, MCP integration)
- **data/** - Data system changes (balance, ContentDB, tres migration)

## Original Location

These files were previously in `/changelogs/features/` before project reorganization.
