### Design Decisions
- **Visual effects approach**: Incremental implementation strategy
  - Phase 5: Simple placeholder visuals (~5 min - white flash for melee attacks)
  - Phase 6: Hybrid visual system (~2 hours - base effects with color/scale customization)
  - Phase 9: Optional unique visual scenes (~1 hour each for hero abilities)
  - Rationale: Start simple, add proper visuals when expanding library where differentiation becomes valuable
- **Melee ability patterns**: Flexible attack pattern system
  - Support for multiple patterns: circle_360, cone_auto_target, cone_directional
  - All patterns use same MeleeAbilityHandler (pattern dispatcher)
  - DamageRegistry provides both get_entities_in_area() and get_entities_in_cone()
  - Example abilities: Whirlwind (circle_360), Spear Thrust (cone_auto_target), Cleave (cone_auto_target with wide angle)
